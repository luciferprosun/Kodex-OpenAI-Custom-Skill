# Historical, Web, Autonomous, and Multi-Agent Telemetry Timeline

Evidence cutoff: 2026-07-18 (Europe/Berlin).

This timeline records when public agent systems and evaluation artifacts appeared. It does **not** infer token use for periods where provider or framework telemetry was not published. “No” below means no usable token accounting was found in the inspected primary artifact; it does not prove that the authors never measured tokens privately.

## Era-level coverage conclusion

- **Early tool-use and ReAct era:** public capability evidence exists; reliable usage telemetry is largely absent.
- **Autonomous-general-agent boom:** implementations are abundant, but comparable historical run-level token records are not.
- **Web-agent era:** rich trajectories, screenshots, DOM/accessibility trees, actions, and verifier outcomes exist; token accounting is usually missing and raw traces carry substantial privacy/security risk.
- **Multi-agent era:** a few papers report aggregate totals, showing potentially extreme input amplification, but samples are too narrow and accounting too coarse for universal priors.
- **Current trajectory era:** trace archives increasingly preserve native agent logs and some frameworks track tokens, yet licensing, schema consistency, hidden-reasoning handling, and representativeness remain major blockers.
