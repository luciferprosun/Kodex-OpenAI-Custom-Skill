## Evidence-status vocabulary

- **Stable documented interface**: explicitly described in current official documentation or OpenAPI.
- **Official source-defined interface**: present in a typed definition in an official repository, but not necessarily covered by a compatibility promise.
- **Local generated observation**: generated by installed CLI tooling; valid for the recorded CLI version only.
- **Private/unstable artifact**: useful for local extraction, but not a public interchange contract and unsafe to republish raw.

## Accounting conclusions

1. **Visible output is not directly measured by Responses usage.** Official token-counting guidance says `output_tokens` includes every generated token, not only visible text. Reasoning tokens are itemized, but other non-visible formatting or channel tokens may not be. Therefore `output_tokens - reasoning_tokens` is not guaranteed to equal visible text tokens. SmartRouter should either tokenize the visible output separately and label it `reconstructed`, or leave the field unknown.
2. **Cached input is not removed from context.** `cached_tokens` measures a cache read and changes billing/latency, not the logical input size. Preserve `input_tokens`, `cached_tokens`, and cache writes separately. A derived non-cached value may be calculated only with a `reconstructed` measurement method.
3. **Cache writes and reads have model- and date-sensitive economics.** The current prompt-caching guide says GPT-5.6-family cache writes are billed at 1.25 times uncached input, while cache reads use the cached-input rate. Older families differ. Store model, service tier, price-table access date, and cache-read/write fields; do not apply today’s price table to historical runs without labeling the reconstruction.
4. **Rate-limit telemetry is not cost telemetry.** API rate-limit headers describe capacity. Codex account rate limits and subscription credits are a separate product surface. Neither can be converted to API dollars without an independently documented mapping.
5. **Organization Usage and Costs APIs are valuable audit aggregates, not run trajectories.** They support reconciliation by time bucket, project, model, batch, and service tier, but they lack task identity, verifier outcome, reasoning tokens, and direct run linkage.
6. **Agents SDK is the strongest official run-level aggregation surface.** It exposes total and per-request usage across model calls, including tools and handoffs, and traces the workflow structure. It still needs application-recorded task IDs, timestamps, outcomes, tool-output sizes, retries, escalations, verification, and privacy controls.
7. **Codex `exec --json` is the safest default Codex telemetry capture.** It can be used with `--ephemeral` to avoid persisted rollout files. Lifecycle item events allow tool-call reconstruction, while `turn.completed.usage` provides versioned per-turn token counts. Persist the CLI version and source measurement status.
8. **Local app-server schemas expose context-window and compaction signals not present in `exec --json`.** These fields are useful for 2B local telemetry, but are currently version-specific observations and must be guarded by schema/version detection.

## Required local joins for SmartRouter

No official surface alone answers accepted-task economics. SmartRouter 2B should assign its own immutable `task_id`, `attempt_id`, `request_id`, and `route_decision_id`; timestamp request, tool, verifier, retry, escalation, and compaction events; record the selected model and reasoning setting; and join those events to official token/cost usage. It must preserve missing values rather than coerce absent provider fields to zero.

## Minimal recommended collection hierarchy

1. Capture Responses/Agents SDK provider-reported usage per request when available.
2. Capture `codex exec --json` events with CLI version for Codex subprocess runs.
3. Use version-gated app-server notifications only when context-window and compaction telemetry are required.
4. Reconcile periodically against Organization Usage and Costs APIs when an authorized administrator elects to do so; this mission did not call those APIs.
5. Never use raw rollout/session JSONL as a public dataset. Extract a field allowlist locally, redact, aggregate, then delete or retain the private source according to operator policy.
