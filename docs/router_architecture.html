Codex Patch Smart Router - Knowledge Library Upgrade

Purpose: deterministic local router for OpenAI Codex CLI. It estimates prompt weight and selects profile/model/sandbox/settings before launch.

Execution Flow

prompt
  -> preprocessor
  -> hard safety override
  -> category scoring
  -> prompt-weight dimensions
  -> tie-breakers
  -> profile policy
  -> launcher --execute gate
  -> prompt_hash-only logging

Non-negotiables

  • No raw prompt logging
  • No shell=True
  • No danger-full-access in V0
  • No auto execution
  • Dry-run default
  • approval_policy = on-request
