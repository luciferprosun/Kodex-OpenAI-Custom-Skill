Evidence cutoff: 2026-07-18 (Europe/Berlin).

The pack selects model identity only. It does not select reasoning effort,
agent count, sandbox, approvals, tools, or action authority. It is not wired
into production routing by this research mission. An unassessed model/domain
pair is `no_route`, not numeric zero and not a permission grant.
